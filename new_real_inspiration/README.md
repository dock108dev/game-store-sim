# Real Period Retail Inspiration

This folder contains owner-added real-life reference images for early-2000s video game retail.

Use these images as period retail construction reference, not as files to copy directly.

Primary extraction targets:

- wire-grid and acrylic game-case shelving
- platform/category header strips
- yellow sale and price stickers
- dense case rows with repeated box art faces
- fluorescent drop ceilings and bright retail lighting
- low commercial carpet and tile floors
- glass display cases and console boxes on counters
- register/counter clutter that is retail-specific, not random
- hanging wall posters, murals, and promo panels
- small-chain signage and simple staff-uniform retail cues

Use `inspiration/` for stylized mall/storefront/game-world scaffold and use this folder for real period-specific product, fixture, and store-density rules.
