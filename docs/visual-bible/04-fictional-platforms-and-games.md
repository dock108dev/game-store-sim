# Fictional Platforms And Games

Status: Active visual bible
Spreadsheet families: Product platform rows, fictional game rows, packaging brand kit rows
Primary IDs: OBJ-096 through OBJ-135, OBJ-136 through OBJ-151, OBJ-190 through OBJ-204

## Target Read

The store needs fictional platforms and games that feel like the era without copying real brands. They should be visually distinct, legally safe, and flexible enough for later catalog growth. Names can change later, so the first priority is a strong visual system, not perfect naming.

## Locked Decisions

- Do not use real platform, retailer, publisher, rating, game, or logo names.
- Avoid close parody that could create legal confusion.
- Current placeholder platform names are not locked.
- Day one needs one starter platform only.
- Platform colors should be visually distinct, not real-brand copies.
- Each platform needs a logo mark, box pattern, case spine style, and shelf/header style eventually.
- Starter games are `Footy 2002` plus one funny/legal-safe adventure RPG sequel-ready title.
- Cover art should be recognizable.
- Tone can be fun/funny, but not lawsuit-bait.

## Platform System

Each platform family should define:

- platform display name
- color pair
- logo mark
- case spine style
- console box style
- accessory box style
- shelf/header style
- era band
- hardware silhouette rules

Do not overfit to old placeholder names. If implementation needs temporary names, use names that are easy to replace in data.

## Starter Platform

Pick one platform for day one. The owner does not care which one as long as it is legal-safe and visually coherent.

Recommended starter platform direction:

- name: `Vortex`
- color pair: deep teal + warm cream, with black trim
- case style: standard black DVD case with teal spine stripe
- console box: clean retail box with a simple rounded-console silhouette, not copied from real hardware
- accessory: small controller box using same teal/cream identity

This is a recommendation, not a locked brand. It exists to stop implementation from stalling on naming.

## Starter Games

### Footy 2002

Purpose: first obvious sports game.

Visual requirements:

- green/white field-inspired cover
- ball/cleat/player silhouette or shield shape
- big year/readable title
- price sticker on case
- stackable duplicates
- legally safe: no real league, team, player, federation, trophy, or logo references

### Adventure RPG Sequel-Ready Title

Temporary recommended name: `Critter Quest II`

Purpose: first anchor adventure/RPG line that can support sequels.

Visual requirements:

- fantasy/adventure composition
- one original creature/companion silhouette or emblem
- warm adventurous color palette
- obvious sequel marker
- no real monster-catching, final-fantasy, or known franchise mark/silhouette references

Alternate temporary names if `Critter Quest II` feels too close later:

- `Tiny Legends II`
- `Pocket Myth II`
- `Questlings II`
- `Rune Pals II`

## Later Fictional Game Families

The spreadsheet contains future rows such as sports, racing, shooter, rhythm, and handheld creature/adventure titles. These are not day-one blockers.

When expanded, each game family needs:

- cover-art template
- sequel/year variant rules
- platform variants
- demand/rarity hooks
- legal-safe iconography

## Legal-Safe Rules

Allowed:

- broad genre references
- fictional platform ecosystems
- generic sports/action/fantasy/racing/music imagery
- original simple symbols and mascots

Not allowed:

- real console names or marks
- real game title riffs that are too close
- real rating logos
- real publisher logos
- real sports league/team/player cues
- real controller or console silhouettes if recognizable

## Rating, Genre, Publisher, Store Icons

Rows OBJ-190, OBJ-191, OBJ-202, OBJ-203, and OBJ-204 should become reusable texture/logo sheets:

- fictional rating icons
- genre icons
- fictional publisher logos
- fictional platform marks
- store brand icon sheet

These should be simple vector/bitmap assets, not 3D label props.

## Validation Shots

Required:

- starter platform header and starter case together
- `Footy 2002` case at player distance
- adventure RPG case at player distance
- starter console box and accessory package using same platform identity

Pass criteria: the products feel like a coherent fictional platform ecosystem and do not resemble copied real IP.
