# Source-of-truth policy

The [README](../../README.md) provides the current setup path. [Module ownership](../02-technical/ssot.md) identifies authoritative code and retired modes. The active game is `encounter/`.

Design and implementation records describe their stated scope. Dated delivery and review records apply to their exact candidates; they are not current setup instructions. Earlier prototypes and old player guides must not override the active game's rules.

Keep documentation aligned with the current implementation. Tie validation results to the tested code and assets, and keep measured behavior separate from design intent and playtest feedback.
