# Inspiration Extraction

## Rule

References are for extraction, not copying.

Use references to answer:

- what shapes exist?
- how dense is the space?
- what materials repeat?
- how does UI communicate?
- what makes the store readable?
- what makes the action feel satisfying?

Do not copy:

- logos
- packaging
- exact layouts
- exact UI
- text
- brand identities
- real products

## Real Retail Extraction Targets

From `real_inspiration/`, extract:

- fixture construction
- shelf density
- product row patterns
- price sticker placement
- category header positioning
- counter clutter types
- lighting color and brightness
- mall/store boundary design
- display-case usage
- backroom/receiving practicality

## Other Game Extraction Targets

From `other_game_inspiration/`, extract:

- first-person simulator readability
- object placement feedback
- UI panel density
- customer visibility
- shop flow legibility
- simplified prop forms
- management overlay behavior

## First Playable Visual Extraction

The first playable should include:

- bright retail lighting
- readable glass storefront
- visible shelf gaps
- colorful fictional cases
- yellow-ish sale/price tags
- physical starter shipment
- a practical counter/register
- simple mall path outside
