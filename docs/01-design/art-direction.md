# Art Direction

## Art Target

Hybrid stylized realism.

The game should feel grounded in early-2000s retail while staying readable, performant, and slightly stylized like a modern simulator.

The next production phase is visual-first. The first 0.3% of the game must look right before additional gameplay breadth is added.

## Mood

Warm nostalgia:

- bright mall lighting
- familiar retail materials
- clean but slightly busy surfaces
- colorful product faces
- visible shelf gaps early
- cardboard and plastic tactility
- inviting small-shop atmosphere

## Real Reference Extraction

Use `real_inspiration/` for:

- wire-grid shelving
- acrylic case rows
- platform/category strips
- yellow price stickers
- fluorescent drop ceilings
- low commercial carpet
- tile/carpet transitions
- glass display cases
- console/accessory boxes on counters
- retail-specific counter clutter
- hanging posters and promo panels
- small-chain signage cues

Do not copy exact brands, layouts, logos, products, or packaging.

## Other Game Inspiration Extraction

Use `other_game_inspiration/` for:

- readable simulator UI
- first-person interaction pacing
- object placement affordances
- simple but clear store surfaces
- stylized prop readability
- customer flow visibility
- management overlay density

Do not copy UI layout, specific art assets, streamer overlays, brand names, or product categories unrelated to this game.

## Visual Language

### Products

Products create color.

Cases, boxes, stickers, and shelf rows should be the main source of visual richness. The environment should support them rather than overpower them.

### Fixtures

Fixtures create structure.

Shelves, racks, counters, and display cases should have readable silhouettes and predictable slot behavior.

### Signage

Signage creates final read.

Use platform/category headers, sale labels, open/closed signs, and small shelf tags. Avoid walls filled with meaningless posters.

Environment:

- mall concourse segment
- storefront glass and frame
- starter store shell
- backroom/receiving area
- counter/register
- backroom computer
- fluorescent ceiling lighting
- commercial carpet/floor material

Fixtures:

## First 0.3% Visual Gate

The visual gate must establish:

- storefront identity from the mall concourse
- correct retail scale for player, cases, shelves, counter, and backroom
- empty shelf capacity that reads as future growth instead of unfinished content
- case rows that visibly communicate one-to-one stock without becoming noisy
- warm nostalgic lighting that still has bright retail clarity
- fictional product art that feels era-appropriate and legally clean
- fixture language that can support future expansion without redesign
- early UI presentation that feels like the game, not debug overlay

The engine proof scene does not satisfy this gate. It only proves that the engine path works.

## Color Direction

Avoid one-note palettes.

The store should combine:

- neutral commercial flooring
- light walls or muted paint
- black/metal/acrylic fixture materials
- yellow sale tags
- colorful fictional box art
- warm accent signage

The game should not be dominated by purple, beige, dark blue, or brown/orange.

## Scale And Readability

Rules:

- shelves must read from normal player distance
- price stickers need symbolic clarity, not tiny readable text everywhere
- cases should be chunky enough to handle
- rows should look dense without requiring expensive physics
- UI text must be legible on Mac laptop screens

## Anti-Goals

Do not make:

- a sterile generic store
- a photoreal brand-copy store
- an overdecorated nostalgia museum
- a joke retail parody
- an unreadable clutter pile
- a showroom with no operational mess

The store should feel like it can do business.
