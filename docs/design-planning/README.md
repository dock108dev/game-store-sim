# Design Planning

This folder is the completed planning record for the opening-store quality-bar attempt.

The current active visual direction has moved to [Visual Production](../visual-production/README.md). Use that folder for final art direction, asset-pipeline planning, visual slice implementation, and visual QA.

Every file should have one clear job:

- Summary docs explain the direction and source references.
- Implementation-plan docs describe one buildable surface or slice.
- Checklist docs define pass/fail review.
- Testing docs define validation and playtest coverage.

## Current Status

The docs in this folder still matter for mechanics, zone intent, screenshot names, nonblocking path/prompt rules, and catalog/decor language. They no longer define the final visual bar and should not be used to justify more visible CSG/label-heavy scene work.

Start visual work with [Visual Production](../visual-production/README.md), not another CSG/label-heavy polish pass.

## Rule

Do not add broad design notes without an implementation path. If a planning note cannot say what file, scene, resource, test, screenshot, or checklist it affects, it belongs in a later brainstorming note, not this folder.
