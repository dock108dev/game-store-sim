# Decision 0003: First Playable Scope

## Status

Accepted.

## Decision

The first playable covers only 0.0%-0.3% completion:

- enter mall store
- receive starter shipment
- pick up physical stock
- price used items
- stock shelves
- move at least one fixture
- open store
- serve physical customers
- complete first sale
- close register
- read daily report
- save/load

## Rationale

The full game-guide describes a long-form retail sim. Starting with the whole system would create uncontrolled scope. The first playable should prove the tactile retail loop before progression expands.

## Out Of Scope

- trade-ins
- returns
- services
- full supplier network
- full secret web
- employees
- expansion
- launch calendar
- rare inventory

## Consequences

- first implementation should be narrow but polished
- docs should validate against this scope
- later systems must attach to the proven loop
