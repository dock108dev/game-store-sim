# Decision 0004: Visual First Gate

## Status

Accepted.

## Decision

After the engine proof, production pauses gameplay breadth and moves to a visual-first benchmark for the first 0.3% of the game.

The first store's visual foundation must be signed off before adding more systems.

## Rationale

Function and logic can expand quickly once the core scaffolding exists. The larger risk is repeating prior visual problems by building gameplay on placeholder visual assumptions.

The first 0.3% defines:

- store scale
- mall storefront language
- fixture language
- product visual grammar
- carried item presentation
- counter/register identity
- backroom/receiving tone
- customer presence from the mall
- report presentation direction

If those are wrong, every later expansion inherits the wrong scaffold.

## Consequences

- Current engine proof remains technical validation, not visual baseline.
- New gameplay systems are blocked unless needed for staging/capturing/validating the visual benchmark.
- Visual benchmark screenshots become required production evidence.
- Human visual sign-off is required; automated nonblank checks are insufficient.
- Later systems must build on the signed-off visual scaffold.
