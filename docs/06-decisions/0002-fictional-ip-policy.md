# Decision 0002: Fictional IP Policy

## Status

Accepted.

## Decision

All in-game brands, products, platforms, games, publishers, suppliers, stores, posters, packaging, and customer references must be fictional.

## Rationale

The game is inspired by early-2000s game retail, but it should not depend on real-world intellectual property. Fictionalization protects the project legally and gives the game its own identity.

## Allowed

- fictional platform names
- fictional game titles
- fictional box art
- fictional publishers
- fictional distributor names
- era-inspired packaging forms
- general retail fixture inspiration

## Not Allowed

- real game titles
- real platform names
- copied box art
- copied logos
- copied store branding
- barely altered parody names that are obviously real brands

## Consequences

- product data needs a fictional naming system
- art pipeline needs original box art and iconography
- validation should eventually scan game data for banned real-world terms
