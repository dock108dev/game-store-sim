# Store Layout Visual Zones

## Purpose

Define the visual job of each store zone before replacing blockout geometry.

## Zone Priority

1. First view: storefront, register, main shelf wall, and backroom hint.
2. Register/counter: transaction clarity and shop identity.
3. Main sales aisle: product density and browsing fantasy.
4. Receiving/backroom threshold: physical stock movement.
5. Backroom office/service: owner work and secondary systems.
6. Optional hidden-thread surfaces: visible but never dominant.

## Storefront And Entry

Visual job:

- Tell the player this is a mid-00s game shop before they move.
- Establish fictional brand.
- Show the shop is small, local, and operational.

Required visual anchors:

- Glass door/window.
- Sign band.
- Posters.
- Window display.
- Entry mat/threshold.
- Clear first route to register and shelves.

## Sales Floor

Visual job:

- Sell product density.
- Separate platform/category areas.
- Make shelves feel browsable.

Required visual anchors:

- Wall of cases.
- Center fixture or aisle.
- New-release faceouts.
- Used-game price stickers.
- Bargain bin.
- Accessory pegboard.

## Register

Visual job:

- Read as the business center.
- Support sale, return, trade-in, preorder, and service without separate workstations.

Required visual anchors:

- Cash drawer.
- Scanner.
- Receipt printer.
- Card terminal.
- Trade-in tray.
- Preorder/service paperwork.
- Impulse rack.

## Receiving And Backstock

Visual job:

- Make stock physically arrive, get checked, and move to shelves.

Required visual anchors:

- Boxes.
- Invoice/check surface.
- Sorted tray.
- Cart/pull stage.
- Backstock shelving.
- Category bins.

## Office And Service

Visual job:

- Make the backroom computer feel like the owner workstation.
- Show service and records as secondary but real.

Required visual anchors:

- Old computer desk.
- Calendar/release board.
- Records shelf.
- Service bench.
- Parts bins.
- Safe/security optional surfaces.

## Hidden Thread

Visual job:

- Add unease through normal retail objects.

Allowed anchors:

- Suspicious invoice.
- Odd supplier note.
- Locked file box.
- Security monitor.
- Cash envelope.

Rule: these props must not look like the main objective.
