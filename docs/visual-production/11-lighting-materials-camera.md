# Lighting Materials Camera

## Goal

Define the visual treatment that makes the store feel authored in first person.

## Lighting Direction

Sales floor:

- Warm fluorescent retail light.
- Soft fixture highlights over shelves.
- Counter as a slightly brighter focal point.
- Window/front light that helps first view.

Backroom:

- Cooler work light.
- More utilitarian shadows.
- Clear receiving/office/service separation.

Avoid:

- Flat editor lighting.
- Dramatic horror lighting for normal retail.
- High-contrast shadows that hide prompts or products.
- Overly saturated neon gamer-room mood.

## Materials

Required material families:

- Painted wall.
- Scuffed laminate/carpet.
- Rubber mat.
- Metal shelf.
- Plastic case.
- Cardboard.
- Paper poster/sign.
- Glass/acrylic.
- Cheap counter laminate.

Every material should be checked at screenshot resolution.

## Camera And Composition

The game is first person. Visual acceptance must happen from normal player height and routes, not editor-overview angles.

Rules:

- First view must explain store identity.
- Register views must support modal context.
- Shelf views must show product density.
- Backroom views must show operation, not random clutter.
- Editor perspective screenshots are useful for critique but not acceptance.

## Postprocess

Possible future additions:

- Ambient occlusion.
- Mild color grading.
- Subtle vignette only if it does not hurt UI.
- Contact shadows.

Do not add postprocess to hide weak assets.

## Acceptance Screenshots

All visual slices should include:

- First-person 1280x720 screenshot.
- One closer inspection screenshot.
- One wide context screenshot.

The current validation screenshots can remain the automated capture set, but visual approval requires human review against this doc.
