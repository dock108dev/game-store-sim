# Mid-00s Game Shop Inventory

## Purpose

Define the visual objects that make the store feel like a mid-00s video game shop.

This is not only product content. It is the physical vocabulary that should appear in meshes, textures, shelves, posters, props, UI labels, and screenshots.

Important: this is the full visual vocabulary for the game over time. It is not the day-one sales-floor loadout. Day one should start restrained: 2 new games, 1 console or refurb hardware box, 1 accessory, and trade-ins as an early inventory-growth path. See [Day One Stock And Unlocks](15-day-one-stock-and-unlocks.md).

## Storefront

Required:

- Glass door and glass window panels.
- Door handle, frame, lock, threshold, and weather strip.
- Open sign or hours decal.
- Store name sign band.
- Window posters for fictional launches and trade-ins.
- Window display shelf with boxed games, accessories, or a console box.
- Sidewalk/strip-mall threshold cue.

Optional:

- Neon-style open sign.
- Sun-faded sale poster.
- Handwritten service or trade-in notice.
- Security sticker using fictional language.

## Sales Floor

Required:

- Wall shelves for used games.
- Freestanding gondola or center aisle fixture.
- New-release wall or endcap.
- Bargain bin.
- Staff-picks area.
- Accessory pegboard or slatwall.
- Locked/glass case for higher-value hardware.
- Product-facing shelf strips and price stickers.

Day-one interpretation:

- Some shelves can be empty or partially dressed.
- A small starter section should be ready for the player to stock.
- Locked category space should read as planned growth, not missing art.

Optional:

- Small demo station.
- Magazine/strategy guide rack.
- Floor mats near register and entry.
- Used-game platform color strips.

## Products

Required:

- DVD-style cases.
- Cartridge cases and loose cartridges.
- Loose discs in sleeves.
- Boxed controllers.
- Memory cards.
- AV/power cables.
- Cleaning kits.
- Refurb console boxes.
- Strategy guides or magazines.
- Service tickets.

Condition cues:

- Cracked case.
- Missing manual sticker.
- Loose media sleeve.
- Reseal sticker.
- Scuffed disc marker.
- Serial/check sticker for suspicious or high-risk items.

## Register Counter

Required:

- Cash drawer.
- Barcode scanner.
- Receipt printer.
- Card terminal.
- Bag/sleeve stack.
- Trade-in inspection tray.
- Preorder binder/card stack.
- Service pickup ticket area.
- Impulse accessory rack.
- Employee-side clutter that does not block interaction.

Optional:

- Counter mat.
- Pen cup.
- Tape dispenser.
- Small handwritten note.
- Customer-facing display.

## Backroom And Receiving

Required:

- Receiving boxes.
- Invoice clipboard.
- Box cutter or tape roll.
- Sorted tray/bin.
- Stock cart or hand truck.
- Backstock shelves.
- Category bins.
- Pull-stage surface.
- Shipping labels.
- Overflow boxes.

Optional:

- Supplier lot labels.
- Return-review crate.
- Damaged goods tray.
- Wall checklist.

## Office And Service

Required:

- Old office computer.
- Keyboard, mouse, printer, and paperwork stack.
- Calendar or release board.
- Records shelf/file boxes.
- Service bench.
- Disc resurfacing or cleaning machine.
- Tool tray.
- Parts bins.
- Ticket board.

Optional:

- Landline phone.
- Corkboard.
- Safe.
- Security monitor.
- Suspicious invoice folder.

## Customers

Required role props:

- Buyer: shopping bag, browsed case, wallet/card gesture.
- Trade-in seller: cardboard box, carried console, stack of games.
- Preorder customer: slip/card or printed reservation.
- Service customer: disc sleeve, controller, repair ticket.
- Suspicious customer: cash envelope, odd invoice, generic package.

Rule: role props should be readable before prompts, but they must not become oversized signs.
