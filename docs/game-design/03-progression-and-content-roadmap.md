# Progression And Content Roadmap

## Progression Philosophy

The player should progress by earning operational capability. Bigger numbers matter, but the main reward is being able to run a more interesting store.

Good unlocks:

- New product category.
- New customer type.
- New fixture type.
- New service workflow.
- New information tool.
- New risk or responsibility.
- New store footprint.

Weak unlocks:

- Pure percentage boosts with no behavior change.
- Decorations that do nothing.
- More products that all behave identically.

## Phase 0: Preproduction

Deliverables:

- Design docs.
- Tech stack decision.
- Data schema sketch.
- Prototype acceptance criteria.
- Placeholder art direction.

Exit criteria:

- We know what the first playable slice is.
- We know which systems are data-driven from day one.
- We know what not to build yet.

## Phase 1: First Playable Counter Loop

Goal: one working day in a tiny store.

Features:

- First-person controller.
- One counter.
- One shelf.
- One backroom box.
- A small product set of fictional used games.
- Pick up item, inspect, price, stock, scan, sell.
- One customer archetype that buys a desired category.
- End-of-day cash summary.

Exit criteria:

- A player can stock and sell items without debug shortcuts.
- Product price and quantity persist for the session.
- The loop has understandable feedback: cash, stock, customer satisfaction.

## Phase 2: Trade-Ins And Used Economy

Goal: make the game about game retail, not generic retail.

Features:

- Customer brings used item.
- Item condition inspection.
- Market value and store demand.
- Cash/store-credit offer.
- Negotiation result.
- Acquired item enters inventory and can be priced/sold.

Exit criteria:

- Trade-ins create meaningful inventory.
- Bad offers have consequences.
- Condition affects resale and reputation.

## Phase 3: Store Layout And Fixtures

Goal: turn the store into a manipulable game board.

Features:

- Buy fixtures from the supplier-ordering interface.
- Place, rotate, and validate fixtures.
- Assign shelf category or product slot.
- Customer pathing uses layout.
- Visibility and queue space affect sales.

Exit criteria:

- Rearranging the store changes customer behavior.
- Fixture choices create clear tradeoffs.

## Phase 4: Ordering, Preorders, And Launch Days

Goal: add planning pressure.

Features:

- Supplier ordering. First pass done as a backroom `Used Game Starter Lot` order.
- Delivery delays. First pass done as next-day receiving-box delivery.
- New release calendar. First pass done as a read-only backroom calendar for fictional launches with countdown, wholesale cost, suggested price, allocation note, and demand tier.
- Preorder deposits. First pass done as a fixed register deposit for one fictional upcoming release customer, tracked separately from sale revenue and profit.
- Allocation limits.
- Launch-day queue and reputation stakes.

Exit criteria:

- The player can overcommit and feel the consequence.
- Planning ahead is more profitable than reacting.

## Phase 5: Services And Events

Goal: broaden the store without losing the core.

Candidate systems:

- Disc resurfacing.
- Console testing and refurbishing.
- Controller repair intake.
- Cartridge cleaning and battery replacement.
- Save-transfer help.
- Trade nights.
- Local tournaments.
- Membership program.
- Buyback promotions.

Exit criteria:

- At least one service creates a new station workflow.
- Events increase traffic and introduce operational strain.

## Phase 6: Expansion And Staff

Goal: scale the business after manual work is already fun.

Features:

- Larger floor plan.
- Backroom expansion.
- Employee roles.
- Staff tasks: register, stocking, cleaning, appraisal, security.
- Training and mistakes.

Exit criteria:

- Staff help with real bottlenecks.
- Larger stores create layout and supervision problems.

## Phase 7: Hidden Thread Escalation

Goal: let suspicious systems emerge from ordinary play.

Features:

- Unusual supplier offers.
- Cash-heavy customers.
- Mislabeled boxes.
- Rare items with impossible provenance.
- Police/media/community pressure.
- Endings based on player choices and evidence.

Exit criteria:

- A player can finish a normal retail run without engaging.
- A curious player can discover a coherent hidden story.
- Choices remain systemic, not just dialogue menu branches.
