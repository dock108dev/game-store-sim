# Primary visual reference

**Kardboard Kings**, Henry's House / Akupara Games. Publisher gameplay gallery: https://akuparagames.itch.io/kardboard-kings . Selected image source: https://img.itch.zone/aW1hZ2UvMTM1OTAyNy84MDM3OTEwLnBuZw==/original/%2BTXv6Y.png . Retained byte-for-byte as `kardboard-kings-publisher.png`; inspected this continuation.

Borrowed principles: fixed oblique floor composition, upright legible customer silhouettes, restrained interior colors, distinct fixture/character values, feet-based perceived depth, and room to read browsing routes around shelf ends. The reference still uses pixel-edged simplified figures and textured furniture. This original sample instead tests smooth inked illustration: teal/ochre on charcoal with warm skin and rust shoes, restrained shadows, enlarged readable head. It is not pixel-art fidelity to the reference. No reference character, room art, logos or UI were copied into runtime. Reference PNG is documentation-only and excluded from Godot imports.

Still inspection supports composition/readability; reference trailer timing and gait were not measured. Sample's eight-way travel, four facing groups, 110 logical-pixel figure, 0.72-second gait and shelf contact are authored test choices, not claims about the reference game's implementation.

Space-opera read-only workflow inspection: `source-assets/S02/recipe.md`, `krita_cleanup.py`, actual KRA/export inventory, `docs/technical-approach.md` and `docs/playtests/S02-owner-feedback.md`. Its first duplicate-limb failure and torso reconstruction informed limb isolation here. Its owner's positive feedback did not transfer to this sample. No space-opera files, source assets, gameplay or running process were modified.
